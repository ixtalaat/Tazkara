# 1. Product Vision
Tazkara is an event ticket management platform that enables organizers to create and manage events while allowing customers to browse, reserve, and purchase tickets online.

The system focuses on:
* event management
* secure ticket booking
* payment processing
* attendee tracking
* scalable backend architecture

The MVP aims to provide a professional backend system with production-ready practices.

---

# 2. Problem Statement
Many small and medium event organizers still rely on manual methods for ticket management, including spreadsheets, messaging apps, and manual attendee tracking.

This creates problems such as:
* overbooking
* inconsistent attendee records
* difficult ticket management
* lack of analytics
* poor customer experience

Tazkara solves these problems by providing a centralized platform for event creation, ticket reservations, and payment handling.
